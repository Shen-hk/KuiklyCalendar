# 更新日志

## Unreleased

### Calendar v1.4

- 优化日程声明 DSL：新增 `calendarEvents {}`、`event(id, date)`、`on(date)` 与 `during(start, end)`；`Calendar` 与 `CalendarAgenda` 共用同一构建入口。
- 为 DSL 增加 `@CalendarDslMarker` 作用域保护，减少嵌套配置时误写到外层 Builder 的风险。
- 新增项目 README、文档索引，以及演示视频和 Release 包的固定占位入口。

### Calendar v1.3

- 新增 `CalendarEventSummary`、`CalendarVisibleRange` 与受控 `events` 数据入口。
- 新增 `visibleRangeChanged`，首次显示及范围变化时按 42 格范围去重派发。
- 新增 `DOTS`、`COUNT_BADGE`、`CUSTOM` 日程标记模式；跨天事件仅索引可见日期。
- 新增独立 `CalendarAgenda`、事件点击回调和自定义列表/空态插槽。
- Demo 新增中文日程摘要与 Agenda 联动场景。

### Calendar v1.2

- 新增 `CalendarSlots`：可替换完整头部、头部子区域、星期、日期内容、标记、底部和空态。
- 新增内置年月面板：`monthPickerEnabled`、`yearRange`、`yearPickerStep`、打开/关闭事件。
- 新增可选默认“回到今天”动作及 `todayActionClick` 回调。
- Demo 新增中文化插槽与快速导航示例。

## Unreleased — Calendar v1.1

- 新增 `CalendarSelection` 统一状态模型，以及 `NONE`、`SINGLE`、`RANGE`、`MULTIPLE` 四种选择模式。
- 新增范围选择连续底色、范围上限、起止日期反向点击策略与跨禁用日期保护。
- 新增多选上限、点击取消选择、`selectionChanged` 与 `selectionRejected` 回调。
- 扩展中文 Demo，增加范围选择和多日期选择可运行示例。

## Unreleased — Issue #1476

- 新增跨端月历组合组件 `Calendar` / `CalendarView`。
- 支持月份切换、42 格日期网格、单日期选中、日期和月份回调。
- 支持 min/max、禁用日期、业务可选谓词、相邻月、多色事件标记和主题。
- 新增 `calendar_demo` 中文可运行演示页。
- 新增纯 Kotlin 日期算法测试、API 文档与 Issue 交付材料。
