# PR 文案草稿（仅文本素材）

## 标题

feat: 新增跨端 Calendar 月历组件，完成 #1476

## 描述

### 背景

实现 #1476 所需的月份展示与切换、日期网格、日期选择高亮和日期回调，并提供可直接访问的中文 Demo。

### 主要变更

- 新增 `Calendar` Compose DSL 入口及 `CalendarView`。
- 新增无时区 `CalendarDate`、`CalendarMonth`、`CalendarTheme`、`CalendarMarker` 等公开模型。
- 使用 `commonMain` 纯 Kotlin 公历算法和 Kuikly `CalendarModule`，不新增第三方依赖或原生扩展。
- 支持范围/多选、禁用/边界、相邻月、周起始日、日程摘要、主题和可组合 Slot。
- 新增 `CalendarAgenda`、`calendarEvents {}` 日程 DSL、`calendar_demo`、测试及中文文档。

### 验证

- 日期算法单测：闰年、世纪年、跨月/跨年、星期与非法输入。
- Demo：路由 `calendar_demo`，可验证选中、禁用、事件标记、月份切换和回调。

### 非本次范围

周/日视图、事件拖拽、跨天横条和完整无障碍语义将在后续独立 Issue 中扩展，避免破坏基础 API。

## 社区宣传要点

- 纯 `commonMain` 实现，Android/iOS/鸿蒙/H5 使用同一套公历网格逻辑。
- 零新增依赖、42 格稳定布局、自然日 API，降低跨端时间坑。
- 从开箱即用的单选日历到日程标记、禁用策略和内容插槽，覆盖常见业务场景。
