# Calendar 组件使用文档

## 快速开始

组件已经位于当前工程 `commonMain`，无需新增依赖。将下列代码放进任一 `Pager.body()` 的容器中：

```kotlin
import com.kuikly.kuiklycalendar.calendar.Calendar
import com.kuikly.kuiklycalendar.calendar.CalendarDate

Calendar {
    attr { selectedDate = CalendarDate(2026, 7, 15) }
    event {
        dateSelected { date ->
            // 业务建议存储 date.format()，例如 2026-07-15
        }
    }
}
```

## 预约场景

```kotlin
Calendar {
    attr {
        minDate = CalendarDate(2026, 7, 3)
        maxDate = CalendarDate(2026, 9, 25)
        isDateSelectable = { date -> date != CalendarDate(2026, 8, 8) }
    }
}
```

## 日程标记与本地化

```kotlin
Calendar {
    attr {
        showAdjacentMonths = true
        markers = mapOf(
            CalendarDate(2026, 7, 15) to CalendarMarker(listOf(0xFF22C55E, 0xFFF59E0B))
        )
        weekdayLabels = listOf("Sun", "Mon", "Tue", "Wed", "Thu", "Fri", "Sat")
        firstDayOfWeek = CalendarWeekday.SUNDAY
    }
}
```

## 日程 DSL

固定的本地日程可直接写在 `attr` 中；单日用 `event(id, date)`，跨日用 `event(id, startDate, endDate)`。`on` 和 `during` 则适合把必填字段一起放进配置块的场景。

```kotlin
Calendar {
    attr {
        events {
            event("review", CalendarDate(2026, 9, 8)) {
                title = "设计评审"
                color = 0xFF8B5CF6
            }
            event {
                id = "release"
                during(CalendarDate(2026, 9, 15), CalendarDate(2026, 9, 17))
                title = "版本发布窗口"
                extra("channel", "stable")
            }
        }
    }
}
```

如果需要在多个组件间共享固定事件列表，使用顶层函数 `calendarEvents { ... }` 创建独立的 `List<CalendarEventSummary>` 快照。服务端数据仍建议转换为 `CalendarEventSummary` 后通过 `setEvents` 回填；完整的可见范围加载与 `CalendarAgenda` 联动示例见 [v1.3 日程说明](14-v1.3日程摘要与Agenda使用说明.md)。

## 日期内容插槽

`dayContent` 仅替换日期单元格内容；组件仍负责禁用校验、点击、选中状态和回调。因此业务不需要重复实现状态机。

```kotlin
dayContent = { state ->
    Text {
        attr { text(if (state.isToday) "今天" else state.date.day.toString()) }
    }
}
```

## 农历与补充文案

农历、节气、节假日和调休数据由业务以 Provider 形式注入；组件只负责把补充文案放在日期数字下方。

```kotlin
Calendar {
    attr {
        showSupplementaryLabel = true
        supplementaryProvider = object : CalendarSupplementaryProvider {
            override fun supplementaryLabel(date: CalendarDate): String? {
                return lunarService.labelOf(date) // 初一、春节、休
            }
        }
    }
}
```

默认选中态为 `42 x 42` 的圆角方形，并使用较小的 `dayWithSupplementaryFontSize` 和 `supplementaryFontSize`。存在日程点时，文字区会自动预留底部空间，确保日期、农历和提示点互不遮挡。

## 迁移与升级

这是新增组件，无存量迁移成本。请不要把 `CalendarDate` 直接当作 UTC 时间戳使用；它表示用户选择的自然日。若服务端需要时间戳，应由业务依照所在地时区在边界层转换。
