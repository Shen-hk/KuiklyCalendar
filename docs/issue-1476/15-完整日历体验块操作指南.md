# 完整日历体验块操作指南

`calendar_demo` 页面顶部的“一站式日历体验”是面向体验者的完整组合示例。它不是新的大组件，而是以一个 `Calendar` 为中心，组合范围选择、快速导航、事件摘要、Footer Slot 和 `CalendarAgenda`，展示推荐的真实业务接入形态。

## 体验功能清单

| 功能 | 操作 | 预期结果 |
| --- | --- | --- |
| 年月快速跳转 | 点击月份标题 | 打开面板，先选择年份、再选择月份；范围限制为 2025—2028 年 |
| 月份导航 | 点击左右箭头 | 切换月份，并显示 42 格可见范围的数据请求提示 |
| 回到今天 | 点击右上角“回到今天” | 回到今天所在月份，不改变已选范围 |
| 普通选日 | 默认直接点击日期 | 最常见的单日期选择，Agenda 展示该日的日程 |
| 范围选择 | 点击“体验连续日期”后，连续点击两个日期 | 显示起止圆角端点与连续区间底色，最大范围为 10 天 |
| 禁用规则 | 尝试点击 9 月 18 日，或让范围跨越该日 | 选择不生效，并显示中文拒绝原因 |
| 日程提示 | 查看日期下方彩色小点 | 小点表示当天日程；跨天发布窗口在每个覆盖日期均可见 |
| Agenda 联动 | 点击日期或范围起点 | 下方 Agenda 自动按当前自然日筛选日程 |
| 日程点击 | 点击 Agenda 中的任一条目 | 显示 `id`、标题和类型的回调结果 |
| 自定义 Footer | 点击“清除选择” | 调用 `CalendarActions.setSelection` 清空，并同步 Agenda 空态 |
| 兼容 Marker | 查看 9 月 23 日 | 无事件时仍按 v1.0 规则显示传统 Marker |

## 设计原则

- 主体验区只使用一个核心 Calendar，避免让体验者在多个孤立示例之间自行拼接心智模型。
- 默认采用最常见的 `SINGLE` 单日期选择；“体验连续日期”开关才会切换为 `RANGE`，避免首次使用者误以为必须点击两次。
- 网络加载不在组件内模拟：`visibleRangeChanged` 只展示应请求的自然日范围，实际应用由业务层回填 `setEvents`。
- Agenda 保持独立，日历不承担长列表、加载态或详情页职责。
