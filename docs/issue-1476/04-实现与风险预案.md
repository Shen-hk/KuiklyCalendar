# 实现计划、自测清单与风险预案

## 已执行实现步骤

1. 使用 `CalendarModule` 在运行时取得今日年月日。
2. 使用纯 Kotlin 格里高利算法计算每月天数、周序与跨月日期。
3. 以周起始日算出网格首日，始终渲染 42 格，避免五周/六周月份切换时页面跳动。
4. 以 `vbind(renderVersion)` 在选择或切月后局部重建网格。
5. 在命中 min/max、禁用集合或业务谓词时阻止点击；导航按钮也随可达月份禁用。
6. 添加中文演示页、单元测试与配套文档。

## 预判风险与措施

| 风险 | 措施 |
| --- | --- |
| 闰年、世纪年、首日偏移计算错误 | 单测覆盖 2024、1900、2000、已知星期日 |
| 时区导致选中日期偏一天 | 对外统一使用 `CalendarDate`；只在内部借助框架取当前自然日 |
| 42 格重绘影响性能 | 固定数量、小层级，不使用列表、图片或原生桥；状态变化只发生在点击/切月 |
| min/max 与相邻月点击冲突 | 统一走 `isSelectable` 与 `canDisplayMonth` |
| 自定义日内容绕开禁用逻辑 | 插槽只替换单元格内容，点击仍由外层组件统一处理 |
