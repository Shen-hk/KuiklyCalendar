# 风险清单与长期迭代建议

## 已知限制

- 已支持单选、范围和多选；尚不包含周/日视图及事件拖拽。
- `CalendarMarker` 是兼容的轻量标记；日程数据应使用 `CalendarEventSummary`，详情列表可交给 `CalendarAgenda` 或业务页面渲染。
- 当前 Windows 环境完成了 Android 与 H5 编译和 Android JVM 单测，iOS 与鸿蒙需在对应宿主环境做视觉和交互回归。

## 建议路线

1. **v1.1**：引入 `CalendarSelectionMode`、`CalendarRange`，以新增回调保持现有单选 API 不变。
2. **v1.2**：增加 Header/marker 内容 Slot、手势切月动画及键盘/无障碍语义；先统一确认 Kuikly 各端事件能力。
3. **v1.3**：以可选独立模块提供农历和节假日数据，避免基础组件引入体积与地区数据维护负担。
4. **质量门禁**：补充 Android/iOS/OH/H5 截图回归，用同一组“月首周日、闰年二月、边界月、相邻月”金标用例锁定跨端一致性。
