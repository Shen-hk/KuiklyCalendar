# Issue #1476 需求规格

## 结论

本次交付的是一个可嵌入任意 Kuikly 页面、零新增第三方运行时依赖的月历组合组件，而不是调用系统日期选择器的包装层。

## 原始诉求拆解

| 类型 | 需求 | 落地情况 |
| --- | --- | --- |
| 硬性 | 显示当前月份标题、前后月份切换 | `CalendarView` 月份标题与左右按钮 |
| 硬性 | 星期表头与正确日期网格 | 固定 6×7（42 格）网格，支持周一或周日为首日 |
| 硬性 | 点击选择与高亮 | 单选态、今日态、禁用态，回调返回 `CalendarDate` |
| 硬性 | 完整事件回调 | `dateSelected`、`monthChanged` |
| 验收 | 多平台 | `commonMain` 实现，Android/iOS/鸿蒙/H5 共用 |
| 加分 | 美观与自然交互 | 圆角卡片、稳定网格、多色日程点、相邻月显示 |

## 真实使用场景

- 预约、签到、出行：限制最小/最大日期，屏蔽不可预约日。
- 工作台/课程表：用多色小圆点表达 1～3 类事件。
- 表单：利用日期回调把自然日交给业务，再由业务自行转成服务器所需时区时间戳。
- 活动页：用 `dayContent` 插槽替换单元格内容，不复制整个日历逻辑。

## 边界与假设

- 仅实现月视图、单日期选择。范围选择、多选、周视图、无限滚动与农历不在本 Issue 范围，避免 API 过早膨胀。
- 日期是无时区的自然日；事件回调不返回时间戳。这避免跨端和夏令时场景产生日期偏移。
- 默认一周从周一开始，中文星期标题；通过属性可改为周日开始或传入本地化标题。
- 兼容当前工程使用的 Kuikly `2.7.0-2.1.21` 及其 Android/iOS/H5/鸿蒙目标；不要求修改原生宿主代码。

## 验收映射

演示路由为 `calendar_demo`，固定 2026 年 7 月展示选中日期、禁用日期、多色标记、相邻月点击切换及两种回调文本，便于人工验收。
