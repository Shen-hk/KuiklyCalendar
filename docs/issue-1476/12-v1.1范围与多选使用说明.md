# Calendar v1.1：范围与多日期选择

## 已实现能力

v1.1 在保持 v1.0 单选 API 不变的基础上，新增统一选择状态、范围选择、多日期选择、选择拒绝回调与连续区间视觉。

| 能力 | 行为 |
| --- | --- |
| 单选 | 默认模式；继续使用 `selectedDate`、`dateSelected` 即可 |
| 范围选择 | 首次点击起始日，第二次点击结束日；中间日期显示连续底色 |
| 多选 | 点击切换日期；支持最大可选天数 |
| 禁用保护 | 不可选日期会派发拒绝回调；范围默认不可跨越不可选日期 |
| 受控状态 | 可用 `selection` 初始化，用 `setSelection()` 程序性同步 |

## 新增模型

```kotlin
sealed class CalendarSelection {
    object None
    data class Single(val date: CalendarDate)
    data class Range(val start: CalendarDate, val end: CalendarDate? = null)
    data class Multiple(val dates: Set<CalendarDate>)
}
```

`Range.end == null` 表示用户刚选择了起始日期，正在等待选择结束日期。范围结束日期必须不早于开始日期。

## 范围选择

```kotlin
Calendar {
    attr {
        selectionMode = CalendarSelectionMode.RANGE
        selection = CalendarSelection.Range(
            start = CalendarDate(2026, 8, 2),
            end = CalendarDate(2026, 8, 6)
        )
        maxRangeDays = 14                 // 0 表示不限制
        rangeOverflowPolicy = RangeOverflowPolicy.RESTART
        disabledDates = setOf(CalendarDate(2026, 8, 9))
        allowRangeAcrossDisabledDates = false
    }
    event {
        selectionChanged { selection ->
            // CalendarSelection.Range(start, end)
        }
        selectionRejected { reason, attemptedDate ->
            // 超过范围、含禁用日期等
        }
    }
}
```

第二次点击早于起始日期时：

- `RESTART`：将该日期作为新起点。
- `SWAP`：自动形成“较早日期至原起点”的完整范围。

范围完整后，起点仅绘制右半段背景，终点仅绘制左半段背景，中间日期绘制整格背景；因此跨周时视觉连续且不会越过网格边缘。

## 多日期选择

```kotlin
Calendar {
    attr {
        selectionMode = CalendarSelectionMode.MULTIPLE
        selection = CalendarSelection.Multiple(
            setOf(CalendarDate(2026, 8, 3), CalendarDate(2026, 8, 8))
        )
        maxSelectionCount = 3             // 0 表示不限制
    }
    event {
        selectionChanged { selection ->
            val dates = (selection as? CalendarSelection.Multiple)?.dates.orEmpty()
        }
        selectionRejected { reason, _ ->
            if (reason == CalendarSelectionRejectedReason.MAX_SELECTION_COUNT_REACHED) {
                // 提示用户已到选择上限
            }
        }
    }
}
```

再次点击已选日期会取消选中；取消最后一个日期时状态自动回到 `CalendarSelection.None`。

## 事件与程序性控制

| API | 触发时机/作用 |
| --- | --- |
| `dateSelected` | 保持 v1.0 兼容，仅在 `SINGLE` 模式点击成功时触发 |
| `selectionChanged` | 任意选择模式发生有效用户变更时触发 |
| `selectionRejected` | 点击禁用日期、范围跨禁用日期、超出范围天数、达到多选上限或禁用选择时触发 |
| `setSelection(value, emitEvent)` | 程序性同步选择；默认不派发回调 |
| `clearSelection(emitEvent)` | 清空选择 |
| `currentCalendarSelection()` | 获取完整选择状态 |
| `currentSelection()` | 兼容 API；范围返回起点，多选返回任意首个日期 |

## 迁移说明

原有单选代码无需修改：`selectedDate` 与 `dateSelected` 保持语义不变。新代码优先使用 `selectionMode + selection + selectionChanged`，以避免为范围和多选维护额外状态机。

## 验收场景

1. 打开 `calendar_demo`，检查“范围选择”预选 7 日至 12 日的连续底色。
2. 点击可用日期依次设置起点、终点；尝试点击 18、19 日，确认出现“不可选”提示。
3. 在范围模式选择超过 14 天的结束日期，确认选择保留且出现拒绝提示。
4. 在“多日期选择”区域点击已选日期取消，再点击新日期；第 4 个日期应被拒绝。
