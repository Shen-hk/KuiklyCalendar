# Calendar v1.2：插槽与快速导航使用说明

v1.2 在不改变 v1.0/v1.1 默认行为的前提下，新增可组合插槽、内置年月跳转面板和可选的“回到今天”动作。它仍是轻量月历：不包含网络日程、滑动无限月历、农历或平台专属无障碍实现。

## 1. 快速开始

```kotlin
Calendar {
    attr {
        initialMonth = CalendarMonth(2026, 11)
        monthPickerEnabled = true
        yearRange = 1970..2100
        yearPickerStep = 12
        showTodayAction = true
        todayActionText = "回到今天"
    }
    event {
        monthChanged { month -> loadMonth(month) }
        monthPickerVisibilityChanged { visible -> reportPickerState(visible) }
        todayActionClick { reportTodayAction() }
    }
}
```

点击默认标题可打开面板：先选择年份，再选择月份。`yearRange` **仅限制面板导航**；最终月份是否允许显示仍由 `minDate`/`maxDate` 决定，日期是否可选仍由原有选择规则决定。

## 2. 插槽 API

在 `attr.slots` 中配置。所有 Slot 接收只读状态和（仅动作类 Slot）`CalendarActions`；请不要在 Slot 内保存或修改组件内部状态。

| Slot | 参数 | 用途 |
| --- | --- | --- |
| `header` | `CalendarHeaderState, CalendarActions` | 完全替换头部，优先级最高 |
| `headerLeading` | `CalendarHeaderState, CalendarActions` | 替换默认上月按钮 |
| `headerTitle` | `CalendarHeaderState, CalendarActions` | 替换默认月份标题 |
| `headerTrailing` | `CalendarHeaderState, CalendarActions` | 替换默认“回到今天 + 下月”区域 |
| `weekday` | `CalendarWeekdayState` | 自定义星期标题 |
| `dayContent` | `CalendarDayState` | 自定义日期单元格；优先于兼容属性 `dayContent` |
| `marker` | `CalendarDayState` | 有 `CalendarMarker` 时自定义标记 |
| `footer` | `CalendarFooterState, CalendarActions` | 在月格下添加业务操作区 |
| `emptyContent` | 无 | 当前月份没有任何可选日期时替换 42 格网格 |

头部优先级固定为：`header` > `headerLeading/headerTitle/headerTrailing` > 默认头部。日期内容优先级为：`slots.dayContent` > 兼容的 `dayContent` > 默认数字与标记。

## 3. 自定义标题与底部

```kotlin
attr {
    monthPickerEnabled = true
    slots = CalendarSlots().apply {
        headerTitle = { state, actions ->
            Text {
                attr { text("${state.displayedMonth.title()} ▾") }
                event { click { actions.showMonthPicker() } }
            }
        }
        footer = { state, actions ->
            Text {
                attr { text("已选：${state.selection}") }
                event { click { actions.showToday() } }
            }
        }
    }
}
```

`CalendarActions` 提供 `showMonth`、`showToday`、`select`、`setSelection`、`showMonthPicker`、`hideMonthPicker`。这样自定义 UI 能复用 Calendar 的边界校验与回调语义。

## 4. 行为与兼容性

- 默认 `monthPickerEnabled = false`、`showTodayAction = false`，因此旧页面视觉和交互不变。
- `showToday()` 仍只改变可见月份，不自动选中今天；若今天所在月份因 `minDate/maxDate` 无法显示，调用会被安全忽略。
- 默认头部只在可见月份不等于今日所在月份时显示“回到今天”。自定义 `footer` 或 `headerTrailing` 可自行调用 `actions.showToday()`。
- 月份变化继续派发 `monthChanged`；从面板跳转也遵循同一事件。面板打开/关闭额外派发 `monthPickerVisibilityChanged`。
- `todayActionClick` 只表示默认头部动作被点击。自定义 Slot 内调用 `actions.showToday()` 不会伪造此业务点击事件。

## 5. Demo 与验收

`calendar_demo` 的“自定义与快速导航：插槽 + 年月面板”覆盖：中文自定义标题、星期 Slot、Marker Slot、Footer Slot、受限年份范围、年月选择和回到今天回调。

验收重点：

1. 点击标题后，面板先展示年份，再展示月份。
2. 年份范围外的翻页按钮不可操作；因 `minDate/maxDate` 不可显示的月份为禁用态。
3. 选择月份后面板关闭，并只触发一次 `monthChanged`。
4. 自定义 Slot 使用 `CalendarActions` 后，月份和选择状态与默认交互保持一致。
